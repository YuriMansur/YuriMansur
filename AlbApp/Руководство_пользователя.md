# AlbApp — руководство пользователя

Программа управления испытательным стендом «Линейная циклика»: проведение испытаний по ГОСТ, запись данных с датчиков, видеофиксация, тренды, протоколы.

---

## 1. Запуск и выбор стенда

При запуске открывается **окно выбора стенда**.

1. В выпадающем списке выберите стенд (например, «Линейная циклика 2.1»).
2. Нажмите **Открыть** — стенд откроется в отдельном окне.

Особенности:

- Каждый стенд работает в **своём окне** и независимо от других. Можно открыть сразу оба стенда — выберите второй в списке и снова нажмите «Открыть».
- В списке показаны только стенды, которые **ещё не открыты**. Уже открытые перечислены строкой «Открыты: …». Если открыты все — список пуст, кнопка недоступна.
- Окно выбора можно закрыть — окна стендов продолжат работать. Чтобы открыть ещё один стенд позже, просто запустите программу снова.
- Стенды отличаются адресом контроллера (ПЛК); набор сигналов, экраны и порядок работы у них одинаковые.

## 2. Окно стенда

### 2.1. Шапка

Вверху окна — постоянная строка:

| Элемент | Назначение |
|---|---|
| **☰** (слева) | Открывает боковое меню вкладок |
| **Название стенда** (по центру, жёлтым) | Какой стенд открыт в этом окне — важно, когда открыто несколько окон |
| **Сброс аварий** (справа, красная) | Снять аварию на стенде после устранения причины |

### 2.2. Меню вкладок

Нажмите **☰** — слева выезжает панель с вкладками:

- **Испытания** — основной рабочий экран
- **Видеоналожение** — наложение графика на записанное видео
- **Тренды** — графики датчиков в реальном времени и из архива
- **Сообщения** — журнал событий (связь, аварии, действия)
- **Экспорт** — журнал проведённых испытаний
- **Протоколы/Журналы** — папки с документами испытаний
- **Настройки**

Панель закрывается сама после выбора вкладки или когда курсор уходит с неё вправо. Повторное нажатие ☰ тоже закрывает панель.

### 2.3. Авария

При аварии на стенде **рамка окна мигает красным**, а карточка «Состояние» на экране «Испытания» показывает **Авария**. Мигание снимается только контроллером — после нажатия **Сброс аварий**, когда причина устранена.

### 2.4. Тема оформления

Тёмная / светлая тема переключается в **Настройки → Прочее → Тема**.

## 3. Вкладка «Испытания»

Экран разделён на четыре колонки (секции).

### 3.1. Секция 1 — Управление стендом и камеры

**Карточка «Состояние»**

| Значение | Что означает |
|---|---|
| **Готовность** (зелёный) | Стенд готов к нагружению |
| **Работа** (синий) | Идёт испытание либо привод движется |
| **Авария** (красный) | Авария на стенде — см. п. 2.3 |
| **—** (серый) | Нет связи с ПЛК, привод обесточен или неисправны датчики (причина — в подсказке при наведении) |

**Ручное управление** (доступно только вне испытания):

- **Вкл. привод / Выкл. привод** — подача и снятие питания привода.
- **Режим управления** — карточка показывает текущий режим (Ручной / Автоматический).
- **Толчок назад / Толчок вперёд** (стрелки ▲ ▼) — привод движется, пока кнопка удерживается.
- **Скорость** — ползунок скорости толчков, мм/с.
- **L** — обнулить показание положения; **Н** — обнулить показание нагрузки.

Активные состояния подсвечиваются на кнопках (привод включён, идёт толчок и т. д.).

**Показания**: **Позиция** (мм), **Нагрузка** (Н), **Скорость** нагружения (Н/с) — живые значения с ПЛК.

**Камеры** (две видеопанели внизу секции). Наведите курсор на панель — появятся кнопки:

| Кнопка | Действие |
|---|---|
| 👁 | Открыть / закрыть камеру (устройство выбирается в Настройках) |
| ● | Начать запись |
| ■ | Остановить запись |

- Запись, запущенная на одной камере, автоматически стартует и на второй открытой камере (и останавливается на обеих). Если вторая камера закрыта — пишется только одна.
- Файлы записи: `rec_<дата_время>_cam1.avi`, `..._cam2.avi` и таблица времени кадров `rec_<дата_время>.csv` в домашней папке пользователя. Таблица нужна для «Видеоналожения».
- **Во время испытания камерами управляет программа**: когда на шаге **НАГРУЖЕНИЯ** оператор нажимает кнопку шага (стенд начинает нагружать), камеры открываются и начинают запись, кнопки на панелях скрываются; когда шаг выполнен или оператор переходит дальше — запись останавливается и камеры закрываются. Подготовка (установка образца, обнуление) и паузы между шагами не снимаются. Если камера не выбрана в настройках или недоступна — испытание идёт без неё, причина показана в статусе панели.

### 3.2. Секция 2 — Параметры испытания и образец

- **Параметры оборудования стенда** — марка, серийный номер, дата аттестации (заполняются в Настройках, здесь только для просмотра).
- **Параметры испытания**:
  - **Стандарт проведения испытаний** (ГОСТ);
  - **Методика** (зависит от ГОСТ);
  - **Уровень нагружения**;
  - **Условие нагружения** (если предусмотрено ГОСТом).
- **Документация (ГОСТ)** — открывает текст выбранного стандарта (PDF).
- **Информация об исследуемом образце**: название, даты получения и проведения, признаки «образец используется» / «взамен разрушенного», применяемые концевые крепления. Эти данные попадают в протокол.

Пока идёт испытание, выбор стандарта, методики, уровня и условия **заблокирован**.

### 3.3. Секция 3 — Ход испытания (мастер)

Список шагов методики слева, содержимое текущего шага справа. Шаги сгруппированы: **НАЧАЛО → ПОДГОТОВКА → НАГРУЖЕНИЕ → ЗАВЕРШЕНИЕ**.

**Порядок работы**

1. Нулевой шаг — **▶ Начать испытание**. По нажатию:
   - на ПЛК уходит команда «испытание идёт»;
   - блокируются ручное управление стендом и выбор ГОСТ/методики.
2. Шаги **ПОДГОТОВКИ** — установка образца, обнуление. Данные и видео на этом этапе не пишутся.
   На шаге «Установка образца» введите **длины сегментов** (верхняя и нижняя, мм) — под полями сразу показываются **расчётные смещения** f и o для каждого сегмента (по таблице 6 ГОСТ Р ИСО 10328 для выбранных в секции 2 уровня нагрузки и условия; для уровней, которых в таблице нет, выводится сообщение).
3. Шаги **НАГРУЖЕНИЯ** (в т. ч. циклического). У такого шага есть кнопка действия — «Fstab = 50 Н», «Приложить Fcmax», «Запустить F-c(t)» и т. п. По её нажатию стенд начинает выполнять шаг, и автоматически:
   - начинается запись данных датчиков в базу;
   - открываются камеры и стартует видеозапись.
   Запись идёт **только пока шаг выполняется**: она останавливается, когда контроллер сообщает о выполнении шага, либо когда оператор переходит к следующему шагу, прерывает испытание или переходит к протоколу. Пока шаг выполнен и стенд просто стоит, ничего не пишется. На следующем шаге запись снова начнётся по его кнопке.
4. Проходите шаги кнопкой **Далее →**. Шаги бывают:
   - информационные (указания оператору);
   - **Установить F = 0** — обнуление силы перед нагружением;
   - шаги нагружения с кнопкой, отправляющей команду на ПЛК (например, `Fstab`, `Fset`);
   - формы для ввода значений и выбора ветки (например, характер повреждения). Выбор ветки может добавить вложенные под-шаги.
5. Последний шаг — **Протокол** (запись в базу и видео к этому моменту уже остановлены): проверьте данные и нажмите **✓ Завершить испытание**. Программа:
   - создаёт папку испытания с **Протокол.docx** и **Журнал.docx** и открывает её;
   - отправляет ПЛК команду завершения;
   - возвращает мастер к началу для следующего образца.

**Прервать** (кнопка ⛔ в заголовке мастера) — досрочная остановка с подтверждением. ПЛК получает команду прерывания, запись останавливается, камеры закрываются, мастер сбрасывается. При разрушении образца в форме шага может быть предусмотрен переход сразу к протоколу с пометкой досрочного завершения.

Щелчок по пройденному шагу в списке показывает его содержимое для просмотра; вернуться к работе — **← Вернуться к текущему шагу**.

### 3.4. Секция 4 — Графики

Три живых графика: **Нагружение, Н**, **Скорость нагружения, Н/с**, **Положение, L мм**; под каждым — окошко текущего значения. Графики работают всегда, независимо от того, идёт ли запись в базу.

## 4. Вкладка «Видеоналожение»

Накладывает график показаний датчиков на записанное с камер видео.

1. **Выбрать записи…** — укажите один или несколько файлов `rec_*.avi`. Рядом с каждым должен лежать `rec_<дата_время>.csv` (создаётся автоматически при записи). Двойной клик по файлу в списке — открыть его в плеере. **Очистить** — убрать список.
2. **Параметры оверлея**:
   - **Окно графика, сек** — сколько секунд истории показывать на графике в кадре;
   - **Размер, % ширины** — размер вставки;
   - **Положение** — угол кадра (правый/левый, нижний/верхний);
   - **Прозрачность** — ползунок;
   - **Каналы** — какие датчики рисовать;
   - **Демо-данные** — синтетический график вместо базы (для проверки внешнего вида).
3. **Создать видео с графиком** — результат сохраняется рядом с исходником как `<имя>_chart.avi`. Ход обработки показан в строке статуса; **Отмена** прерывает.

Данные для графика берутся из базы за время записи ролика по данным этого стенда. Если за период записи данных нет (ролик снят вручную вне нагружения) — файл пропускается с сообщением.

## 5. Вкладка «Тренды»

Справа от заголовка — переключатель режима:

- **Live** — данные в реальном времени по мере поступления с ПЛК.
- **Архив** — данные из базы за выбранный период: задайте даты и время **С / По** и нажмите **Загрузить**.

**Каналы** — панель под переключателем. Для каждого канала:

- флажок — показать/скрыть на графике;
- ползунок — прозрачность линии;
- кнопка точек — показывать маркеры отсчётов;
- правая кнопка мыши по строке — **Цвет линии…**, **Скрыть/Показать канал**.

**График**:

- колесо мыши — масштаб, перетаскивание — сдвиг; клавиши **←** / **→** — панорамирование по времени;
- правая кнопка мыши — контекстное меню: **Сетка** (по X, по Y, прозрачность), автомасштаб, **Экспорт → CSV / Excel** (сохранить видимые кривые в файл), экспорт картинки.

В архивном режиме при большом диапазоне данные прореживаются автоматически, чтобы график оставался отзывчивым.

## 6. Вкладка «Сообщения»

Журнал событий стенда.

- **Режим**: **События** — живая лента текущего сеанса; **Архив** — записи из базы.
- **Уровень**: Все / INFO / WARN / ALARM (аварии выделены красным, предупреждения — жёлтым).
- **Источник**: Все / Связь / ПЛК / Действие / Система.
- **С / По** — фильтр по дате (в режиме «Архив»); границы дат ограничены реально имеющимися записями.

Что попадает в журнал: установление/потеря/восстановление связи с ПЛК, переподключения, аварии и события по сигналам ПЛК, действия оператора. Записи старше **30 дней** удаляются автоматически.

## 7. Вкладка «Экспорт»

Журнал проведённых испытаний: номер, время начала, ГОСТ/методика, образец, статус (идёт / завершено / прервано / авария). Фильтр **Статус** ограничивает список; выберите испытание — ниже показываются его события и измерения. Вкладка только для просмотра.

## 8. Вкладка «Протоколы/Журналы»

Навигатор по папкам испытаний (каждое завершённое испытание — своя папка с `Протокол.docx` и `Журнал.docx`).

- Список обновляется **автоматически** при появлении новых файлов.
- Двойной клик по папке — войти внутрь, по файлу — открыть в Word.
- Кнопки справа от заголовка: **←** назад к предыдущей папке, **↑** на уровень выше. Выше корневой папки документов выйти нельзя.
- Внизу — количество испытаний / файлов в текущей папке.

---

## 9. Вкладка «Настройки»

Две секции.

### 9.1. Стенд и испытание

- **Параметры оборудования стенда** — марка и модель, серийный номер, дата аттестации. Нажмите **Записать** — значения появятся в секции 2 экрана «Испытания» и в протоколах.
- **Параметры испытания** — ГОСТ, уровень, условие и значения сил (F) для выбранной комбинации. **Записать** сохраняет их в конфигурацию; экран «Испытания» перечитывает данные сразу.

### 9.2. Прочее

- **Наладка** — окно наладочных операций стенда (открывается отдельно, не мешает основному окну).
- **Тема** — тёмная / светлая.
- **Камеры**:
  - список доступных устройств (обновляется автоматически при подключении камер);
  - для каждой из двух камер стенда — выбор устройства, разрешения и частоты кадров;
  - **Сохранить настройки** — применить. Во время видеозаписи настройки камер заблокированы.

## 10. Где хранятся данные

Все данные стенда лежат в его папке `stands/<номер стенда>/` рядом с программой:

| Файл / папка | Содержимое |
|---|---|
| `documents/` | Папки испытаний с протоколами и журналами (вкладка «Протоколы/Журналы») |
| `logs.db` | Журнал сообщений (вкладка «Сообщения») |
| `export.db` | Журнал испытаний (вкладка «Экспорт») |
| `camera_settings.json` | Настройки камер |
| `app.log` | Технический лог программы и связи с ПЛК (для диагностики) |

Данные датчиков (тренды, видеоналожение) хранятся в общей базе данных InfluxDB, но каждое окно видит только данные своего стенда. Видеозаписи камер — в домашней папке пользователя.

## 11. Типовые ситуации

| Ситуация | Что делать |
|---|---|
| Карточка «Состояние» показывает «—», в «Сообщениях» — «Связь с … потеряна» | Проверьте контроллер и сеть. Программа переподключается сама; при восстановлении появится сообщение «Связь … восстановлена» |
| Рамка окна мигает красным | Устраните причину аварии на стенде и нажмите **Сброс аварий** |
| Камера «не выбрана в настройках» / «недоступна» | Настройки → Прочее → Камеры: выберите устройство и сохраните. Проверьте, что камера не занята другой программой |
| В окне выбора стенда нужного стенда нет в списке | Он уже открыт — найдите его окно на панели задач |
| Кнопки ручного управления неактивны | Идёт испытание — ручное управление заблокировано до его завершения или прерывания |
| На видеоналожении «нет данных в базе за период записи» | Ролик записан вручную вне выполнения шага нагружения (данные в базу пишутся только пока стенд выполняет шаг) либо для него нет файла `.csv` |
